# Akira Arcade 0.1.0

The first release of Akira Arcade: Delta for iPad, plus phones as game controllers. Built on Delta 2.0 (177).

## New

- **Phone Controller.** Open it from the pause menu, scan the QR code with a phone on the same Wi-Fi, and the phone's browser becomes a gamepad. No app to install on the phone.
- **Pads styled after each console:** NES, SNES, Game Boy / Color / Advance, DS, Mega Drive and N64. The pad changes when the iPad switches to a game on another console.
- **N64 from a phone:** a thumb stick, C buttons, A/B, and Z as a big shoulder button.
- **Up to 4 phones** at once, each with its own player colour.
- **Touch zones like a real pad:** the left side of the screen is the D-pad (or stick), the right side presses the nearest button, a thumb between two buttons presses both, and sliding moves the press. Big L/R buttons for racing games.
- **Join Wi-Fi QR:** type the Wi-Fi password once on the iPad and phones join the network with one scan. The password stays in the iPad's Keychain.
- **Saved link:** a phone that added the pad to its Home Screen can rejoin later. **New Link** replaces it.
- **About Akira Arcade** in Settings: credits, source code, license, privacy.

## Install

- **AltStore or SideStore:** add the source `https://raw.githubusercontent.com/yamustofa/akira-arcade/main/altstore/source.json`, or install `AkiraArcade.ipa` from this release. Apps installed with a free Apple ID need refreshing every 7 days.
- **From source:** see the README (Xcode and a free Apple ID).

Akira Arcade ships no games or BIOS files. Play games you own, or free homebrew.

## Known issues

- **Delta Sync with Dropbox or Google Drive, and Patreon features** use Delta's own accounts and keys, so they may not work in this fork.
- **No tactile feel on glass.** For long sessions, a Bluetooth controller works alongside the phones.
- **iPhone Safari can't go full screen from a page.** Add the pad to the Home Screen, or use aA → Hide Toolbar.
- Phones and iPad must be on the same Wi-Fi (a phone's Personal Hotspot works too).
